Figure 7 shows the **Cadence Virtuoso transistor-level implementation** of the proposed LDO regulator. The circuit consists of a **two-stage error amplifier, Miller compensation network, PMOS pass transistor, feedback network, output capacitor, and load current source**. The design is implemented using CMOS transistors and biased through a constant current source to achieve stable voltage regulation.

---

## 1. Bias Circuit (NM3 and NM2)

On the left side of the schematic, a **25 µA bias current source (I5)** is connected to transistor **NM3**.

### NM3

- Diode-connected NMOS transistor.
- Generates a bias voltage (**V<sub>bias</sub>**).
- Converts the reference current into a gate bias voltage.

### NM2

- Shares the same gate voltage as NM3.
- Forms an NMOS current mirror with NM3.
- Mirrors the bias current and supplies the tail current of the differential pair.

### Purpose

The NM3–NM2 current mirror establishes a stable operating point for the error amplifier and ensures proper transistor biasing independent of load conditions.

---

## 2. First Stage Error Amplifier

The first stage consists of:

- NM0
- NM1
- PM2
- PM0

### NM0 and NM1 (Differential Pair)

These transistors form the differential input stage.

#### Inputs

- NM0 gate → V<sub>ref</sub>
- NM1 gate → V<sub>fed</sub>

The differential pair continuously compares:

**V<sub>error</sub> = V<sub>ref</sub> − V<sub>fed</sub>**

and converts the voltage difference into a current difference.

---

### PM2 and PM0 (Active Load)

PM2 is diode-connected and PM0 acts as the mirror transistor.

#### Functions

- Provide active loading
- Convert differential current into a single-ended output
- Increase voltage gain

The output of the first stage appears at the drain node of NM1 and PM0.

---

## 3. Miller Compensation Network

Between the first-stage output node and the second-stage output node, a compensation network consisting of:

- **R<sub>c</sub> = 500 Ω**
- **C<sub>c</sub> = 5 pF**

is connected.

### Function of C<sub>c</sub>

The compensation capacitor creates pole splitting and introduces a dominant pole, thereby improving loop stability.

### Function of R<sub>c</sub>

The series resistor eliminates the right-half-plane (RHP) zero normally generated by Miller compensation and improves phase margin.

### Benefit

The R<sub>c</sub>–C<sub>c</sub> network stabilizes the two-stage amplifier and prevents oscillations under varying load conditions.

---

## 4. Second Gain Stage

The second stage consists of:

- PM1
- NM4

### PM1

PM1 operates as a common-source amplifier.

#### Functions

- Receives the first-stage output signal
- Provides additional voltage gain
- Drives the gate capacitance of the pass transistor

---

### NM4

NM4 acts as an active current sink.

#### Functions

- Provides bias current to PM1
- Increases output resistance
- Enhances gain of the second stage

The output of this stage drives the gate of PM3.

---

## 5. PMOS Pass Transistor (PM3)

PM3 is the large PMOS transistor located near the output node.

### Function

PM3 acts as the pass element of the LDO.

It regulates current flow from:

**V<sub>DD</sub> → V<sub>OUT</sub>**

according to the control signal generated by the error amplifier.

### Operation

#### When

**V<sub>OUT</sub> < V<sub>desired</sub>**

The gate voltage of PM3 decreases.

##### Result

- PM3 turns ON harder
- More current flows to the load
- Output voltage increases

#### When

**V<sub>OUT</sub> > V<sub>desired</sub>**

The gate voltage increases.

##### Result

- PM3 conduction decreases
- Output voltage falls back to regulation

---

## 6. Feedback Network

The feedback divider consists of:

- **R1 = 220 kΩ**
- **R2 = 120 kΩ**

The divider generates the feedback voltage:

**V<sub>fed</sub> = V<sub>OUT</sub> × [R<sub>2</sub> / (R<sub>1</sub> + R<sub>2</sub>)]**

which is applied to NM1.

At steady state:

**V<sub>fed</sub> = V<sub>ref</sub>**

Therefore:

**V<sub>OUT</sub> = V<sub>ref</sub>(1 + R<sub>1</sub>/R<sub>2</sub>)**

Substituting values:

**V<sub>OUT</sub> = V<sub>ref</sub>(1 + 220kΩ/120kΩ)**

**V<sub>OUT</sub> ≈ 2.83V<sub>ref</sub>**

Thus, the output voltage is determined by the resistor ratio.

---

## 7. Output Capacitor and ESR

The output network consists of:

- **R4 = 2 Ω** (ESR)
- **C2 = 2 µF** (Output Capacitor)

### Output Capacitor (C2)

#### Functions

- Stores charge
- Supplies transient load current
- Reduces output ripple
- Improves load regulation

---

### ESR Resistor (R4)

Models the equivalent series resistance of the capacitor.

Creates an ESR zero:

**f<sub>z,ESR</sub> = 1 / (2π × ESR × C<sub>OUT</sub>)**

which contributes positive phase shift and improves stability.

---

## 8. Load Current Source

The current source (**I10**) represents the load connected to the regulator output.

### Function

- Draws load current from the regulator
- Used during simulation to evaluate load regulation and transient response

When load current changes:

- C2 initially supplies or absorbs charge
- The error amplifier senses the resulting voltage deviation
- PM3 adjusts its conduction
- Output voltage returns to its regulated value
