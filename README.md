# High-PSRR-LDO-Design-Using-90nm-Technology
Designed a high-stability CMOS LDO regulator in GPDK 90nm using Cadence Virtuoso. Achieved 1.704 V regulated output from 1.8 V input with 96 mV dropout, -80.76 dB PSRR, 68.65° phase margin, and robust PVT-corner performance for low-power PMU applications.
